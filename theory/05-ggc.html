บทที่ 5

G/G/c และเปอร์เซ็นไทล์ของเวลารอ

สูตรที่ FlowLens ใช้จริงในการตัดสินใจ — เพราะมันรับความผันแปรที่วัดได้จากข้อมูล เข้าไปตรง ๆ และเพราะเป้าหมายของโรงพยาบาลเขียนเป็น p90 ไม่ใช่ค่าเฉลี่ย

1. ทำไมต้องมีสูตรอีกชุด

M/M/c สมมติว่าเวลาบริการเป็น exponential ซึ่งแปลว่า cs² = 1 เสมอ แต่เวลาเจาะเลือดจริงมี cs² = 0.20 ความต่างนี้ไม่ใช่เรื่องเล็ก เพราะเวลารอเป็นสัดส่วนตรงกับ (ca² + cs²)/2

2. สูตร Sakasegawa

$$W_q^{G/G/c} \;\approx\; \frac{\rho^{\sqrt{2(c+1)}-1}}{c\,(1-\rho)} \;\cdot\;\frac{c_a^{2}+c_s^{2}}{2} \;\cdot\; E[S]$$
โครงเดียวกับ VUT ของ Kingman ทุกประการ — เปลี่ยนแค่พจน์ U ให้รองรับหลายโต๊ะ

เทียบสามสูตรให้เห็นว่าต่างกันตรงไหน:

สูตรพจน์ Vพจน์ Uพจน์ T
Kingman (G/G/1)(ca²+cs²)/2 ρ/(1−ρ)E[S]
Sakasegawa (G/G/c)(ca²+cs²)/2 ρ^(√(2(c+1))−1) / (c(1−ρ))E[S]
M/M/c (ตรง)1 C(c,a)/(cμ−λ) ÷ E[S]E[S]
เมื่อ c = 1 เลขชี้กำลังจะเป็น √4 − 1 = 1 ทำให้ Sakasegawa กลายเป็น Kingman พอดี

Allen–Cunneen — อีกชื่อของสูตรเดียวกัน

ตำราบางเล่มเขียนเป็น $W_q^{G/G/c} \approx \dfrac{c_a^2+c_s^2}{2}\cdot W_q^{M/M/c}$ คือเอาผลของ M/M/c มาคูณด้วยตัวประกอบความผันแปรโดยตรง (เรียก Allen–Cunneen approximation) ทั้งสองวิธีให้ผลใกล้เคียงกันมาก FlowLens เลือกใช้รูป Sakasegawa เพราะคำนวณได้โดยไม่ต้องเรียก Erlang-C จึงเร็วกว่าเมื่อต้องวนคำนวณหลายพันช่วงเวลา

ตัวอย่างที่ 5.1 — จุดเจาะเลือด 7 โต๊ะ เทียบ 11 โต๊ะ
λ = 1.732 ราย/นาที E[S] = 4.2 นาที ca² = 1.00 (Poisson) cs² = 0.20 (วัดได้) a = λE[S] = 7.274 erlang ── 7 โต๊ะ (ที่เปิดจริง) ────────────────────── ρ = 7.274 / 7 = 1.039 ≥ 1 Wq = ∞ ← ไม่มีสมดุล คิวโตไม่หยุด ── 11 โต๊ะ (ตามที่ config ประกาศ) ───────────── ρ = 7.274 / 11 = 0.6613 เลขชี้กำลัง = √(2×12) − 1 = 3.899 ρ^3.899 = 0.1994 U = 0.1994 / (11 × 0.3387) = 0.05352 V = (1.00 + 0.20) / 2 = 0.60 T = 4.2 Wq = 0.05352 × 0.60 × 4.2 = 0.13 นาที (ประมาณ 8 วินาที)

ผลต่างระหว่าง 7 กับ 11 โต๊ะ ไม่ใช่ "รอนานขึ้นนิดหน่อย" แต่เป็น ความต่างระหว่างระบบที่ทำงานได้กับระบบที่พังทุกเช้า

แต่คำตอบ "0.13 นาที" ยังไม่ใช่เรื่องจริงทั้งหมด — λ = 1.732 คือค่าเฉลี่ยของช่วง 06:30–09:00 ส่วนครึ่งชั่วโมงแรกจริง ๆ λ = 2.813 ซึ่งทำให้ ρ = 1.074 แม้มี 11 โต๊ะ สูตรคิวทุกสูตรในบทนี้สมมติว่า λ คงที่ จึงใช้ไม่ได้กับช่วงที่โหลดพุ่งชั่วคราว ต้องใช้วิธีของ บทที่ 9

3. เปอร์เซ็นไทล์ — สิ่งที่เป้าหมายจริงเขียนไว้

ไม่มีโรงพยาบาลไหนตั้งเป้าว่า "เวลารอเฉลี่ยไม่เกิน 15 นาที" เพราะค่าเฉลี่ยซ่อนคนที่รอ 2 ชั่วโมงไว้ได้สบาย เป้าจริงเขียนแบบ "ผู้ป่วย 90% ต้องรอไม่เกิน 15 นาที" ซึ่งคือเปอร์เซ็นไทล์ที่ 90 ของเวลารอ

ปัญหาคือ ไม่มีสูตรปิดสำหรับเปอร์เซ็นไทล์ของ G/G/c FlowLens จึงใช้วิธีผสมสองขั้น

  1. ใช้หาง exponential ของ M/M/c เป็นรูปร่างพื้นฐาน เพราะ M/M/c มีสูตรปิดสวยงาม $P(W_q>t)=C\,e^{-(c\mu-\lambda)t}$ จัดรูปย้อนกลับได้
    $$t_p \;=\; \frac{1}{c\mu-\lambda}\,\ln\!\left(\frac{C(c,a)}{1-p}\right)$$
  2. ปรับสเกลด้วยอัตราส่วนของค่าเฉลี่ย เพราะรูปร่างของหางใกล้เคียงกัน แต่ขนาดต่างกันตามความผันแปร
    $$W_q(p) \;=\; t_p \times \underbrace{\frac{W_q^{G/G/c}}{W_q^{M/M/c}}}_{\text{ตัวปรับสเกล}}$$
  3. กรณีขอบ ถ้า $C(c,a) \le 1-p$ แปลว่าคนน้อยกว่า (1−p) ต้องรอเลย → เปอร์เซ็นไทล์ที่ p เท่ากับ 0 พอดี (เช่น ถ้ามีคนต้องรอแค่ 8% แล้ว p90 ของเวลารอ = 0 นาที) 
def wq_percentile(lam, service_mean, c, p=0.9, ca2=1.0, cs2=1.0):
    mu   = 1.0 / service_mean
    cw   = erlang_c(c, lam / mu)
    rate = c * mu - lam
    base = max(0.0, math.log(cw / (1.0 - p)) / rate) if cw > (1.0 - p) else 0.0
    mmc   = wq_mmc(lam, service_mean, c)
    ggc   = wq_sakasegawa(lam, service_mean, c, ca2, cs2)
    scale = (ggc / mmc) if mmc > 0 and math.isfinite(ggc) else 1.0
    return base * scale

ข้อจำกัดที่ควรรู้

วิธีนี้ไม่ใช่สูตรที่พิสูจน์ได้ว่าแม่น แต่เป็นการประมาณที่ใช้งานได้ดี เมื่อ cs² ไม่ต่างจาก 1 มากเกินไป ถ้า cs² ต่ำมาก (< 0.1) หางจริงจะสั้นกว่า exponential ทำให้ p90 ที่คำนวณได้สูงเกินจริงเล็กน้อย — ซึ่งปลอดภัยกว่าการประเมินต่ำ FlowLens จึงใช้ค่านี้สำหรับ "คัดกรองว่าหน่วยไหนน่าห่วง" แล้วยืนยันตัวเลขสุดท้าย ด้วยการจำลอง (บทที่ 9) ก่อนออกรายงาน

สรุปบทที่ 5

  • Sakasegawa คือ VUT ของ Kingman ที่ขยายให้รองรับหลายโต๊ะ — และเป็นสูตรหลักของ FlowLens
  • ใช้ ca² และ cs² ที่วัดจากข้อมูลจริง ไม่ใช่สมมติ = 1
  • เปอร์เซ็นไทล์คำนวณจากหาง exponential ของ M/M/c แล้วปรับสเกลด้วยอัตราส่วน G/G/c ÷ M/M/c
  • ถ้า P(ต้องรอ) น้อยกว่า (1−p) เปอร์เซ็นไทล์ที่ p เท่ากับ 0 — คนส่วนใหญ่ไม่ต้องรอเลย
  • สูตรทุกตัวใช้ได้เฉพาะเมื่อ ρ < 1 และสถานะคงตัว นอกจากนั้นต้องจำลอง
