บทที่ 4

M/M/1, M/M/c และ Erlang-C

แบบจำลองคลาสสิกที่ทุกตำราเริ่ม และเป็นฐานของสูตรที่แม่นกว่าในบทถัดไป จบบทนี้คุณจะคำนวณได้ว่า "เปิด c โต๊ะ แล้วกี่ % ของคนไข้ต้องรอ และรอนานแค่ไหน"

ลองยืนดูจุดเจาะเลือดจากมุมสูง แล้วจดแค่ตัวเลขเดียวไว้ตลอดเช้า: ตอนนี้มีคนอยู่ในห้องกี่คน ตัวเลขนั้นขยับขึ้นทีละหนึ่งเมื่อมีคนเดินเข้ามา และลงทีละหนึ่งเมื่อมีคนเจาะเสร็จเดินออกไป ไม่มีอย่างอื่นเกิดขึ้นเลย

ทั้งบทนี้คือการเอาตัวเลขที่ขึ้น ๆ ลง ๆ ตัวนั้นมาตอบสองคำถาม — โดยเฉลี่ยแล้วมันค้างอยู่ที่เท่าไร และ คนที่เดินเข้ามาตอนนี้ต้องรอกี่นาที คำตอบออกมาเป็นสูตรที่ศูนย์บริการลูกค้าทั่วโลกใช้จัดกำลังคนมาร้อยปีแล้ว

ถ้าไม่อยากลุยสูตร ข้ามไปอ่าน หัวข้อ 5 เรื่องการรวมคิว ได้เลย — เป็นข้อเสนอที่ลดเวลารอได้ 90% โดยไม่ต้องเพิ่มคนแม้แต่คนเดียว และอ่านรู้เรื่องโดยไม่ต้องผ่านหัวข้อ 1–4

1. กระบวนการเกิด–ตาย: เครื่องจักรที่อยู่เบื้องหลัง

มองระบบคิวเป็น "จำนวนคนในระบบ" ที่กระโดดขึ้นลงทีละหนึ่ง ขึ้นเมื่อมีคนมา (อัตรา λ) ลงเมื่อมีคนเสร็จ (อัตรา μ) นี่คือ กระบวนการเกิด–ตาย (birth–death process)

เมื่อระบบนิ่งแล้ว อัตราที่ข้ามเส้นแบ่งระหว่างสถานะ n กับ n+1 ไปทางขวา ต้องเท่ากับอัตราที่ข้ามกลับมาทางซ้ายพอดี เรียกว่า สมการสมดุล (balance equation)

$$\lambda\, p_n \;=\; \mu\, p_{n+1} \qquad\Longrightarrow\qquad p_{n+1} \;=\; \frac{\lambda}{\mu}\, p_n \;=\; \rho\, p_n$$

วนซ้ำจาก p₀ จะได้ $p_n = \rho^n p_0$ และเพราะผลรวมความน่าจะเป็นต้องเท่ากับ 1

$$\sum_{n=0}^{\infty}\rho^n p_0 = 1 \;\Longrightarrow\; \frac{p_0}{1-\rho}=1 \;\Longrightarrow\; \boxed{\,p_n = (1-\rho)\rho^n\,}$$
อนุกรมเรขาคณิตลู่เข้าได้ก็ต่อเมื่อ ρ < 1 — นี่คือที่มาของเงื่อนไขเสถียร

2. สูตร M/M/1 ครบชุด

$$L=\frac{\rho}{1-\rho}\qquad L_q=\frac{\rho^{2}}{1-\rho}\qquad W=\frac{E[S]}{1-\rho}\qquad W_q=\frac{\rho\,E[S]}{1-\rho}$$

ทั้งสี่สูตรเชื่อมกันด้วยกฎของลิตเติลทั้งหมด: $L=\lambda W$, $L_q=\lambda W_q$ และ $W = W_q + E[S]$ ถ้าจำได้สูตรเดียว ที่เหลือสร้างเองได้

ตัวอย่างที่ 4.1 — โต๊ะทวนสอบผลโต๊ะเดียว
E[S] = 2.0 นาที μ = 0.5 ราย/นาที λ = 0.40 ราย/นาที ρ = 0.40 × 2.0 = 0.80 Wq = ρE[S]/(1−ρ) = 0.80 × 2.0 / 0.20 = 8.0 นาที W = Wq + E[S] = 8.0 + 2.0 = 10.0 นาที Lq = λWq = 0.40 × 8.0 = 3.2 คน L = λW = 0.40 × 10.0 = 4.0 คน ตรวจ: L − Lq = 4.0 − 3.2 = 0.8 = ρ ✓ (คนกำลังรับบริการโดยเฉลี่ย)

ถ้า λ เพิ่มแค่ 10% เป็น 0.44 → ρ = 0.88 → Wq = 14.7 นาที งานเพิ่ม 10% แต่เวลารอเพิ่ม 84% นี่คือความไม่เป็นเชิงเส้นที่ทำให้การวางแผนด้วยค่าเฉลี่ยล้มเหลว

3. M/M/c — หลายโต๊ะ คิวเดียว

เปลี่ยนจากโต๊ะเดียวเป็น c โต๊ะที่ แชร์คิวเดียวกัน อัตราการระบายงานจะเพิ่มขึ้นตามจำนวนคนที่กำลังทำงาน: $\mu_n = \min(n,c)\cdot\mu$

$$p_n=\begin{cases} \dfrac{a^{n}}{n!}\,p_0 & n < c\\[8pt] \dfrac{a^{n}}{c!\,c^{\,n-c}}\,p_0 & n \ge c \end{cases} \qquad a=\lambda E[S]$$

Erlang-C — ความน่าจะเป็นที่ต้องรอ

$$C(c,a)\;=\;P(\text{ต้องรอ})\;=\; \frac{\dfrac{a^{c}}{c!}\cdot\dfrac{1}{1-\rho}} {\displaystyle\sum_{k=0}^{c-1}\frac{a^{k}}{k!}+\frac{a^{c}}{c!}\cdot\frac{1}{1-\rho}}$$
$$\boxed{\;W_q \;=\; \frac{C(c,a)}{c\mu-\lambda}\;}$$
ตีความง่าย ๆ: ต้องรอด้วยโอกาส C เท่านั้น และถ้าต้องรอ จะรอเฉลี่ย $1/(c\mu-\lambda)$ นาที

ปัญหาเชิงตัวเลข และวิธีที่โค้ดจริงแก้

สูตรข้างบนมี $a^{c}/c!$ ซึ่งเมื่อ c = 20 (เครื่องเคมีคลินิกในกรณีศึกษา) ตัวเศษและตัวส่วนจะใหญ่เกินกว่าที่คอมพิวเตอร์จะเก็บได้ FlowLens จึงใช้ สูตรเวียนของ Erlang-B แทน ซึ่งไม่มีการคูณแฟกทอเรียลโดยตรง

$$B(0,a)=1,\qquad \frac{1}{B(i,a)} = 1 + \frac{i}{a}\cdot\frac{1}{B(i-1,a)},\qquad C(c,a)=\frac{B(c,a)}{1-\rho\,[1-B(c,a)]}$$ 
def erlang_c(c, a):
    rho = a / c
    if rho >= 1: return 1.0
    inv_b = 1.0
    for i in range(1, c + 1):
        inv_b = 1.0 + inv_b * i / a      # สูตรเวียน ไม่ล้น
    b = 1.0 / inv_b
    return b / (1.0 - rho * (1.0 - b))

4. Service level — "รอไม่เกิน t นาที กี่ %"

ใน M/M/c เวลารอมีหางเป็น exponential พอดี ซึ่งทำให้คำนวณเปอร์เซ็นไทล์ได้ตรง ๆ

$$P(W_q > t)\;=\;C(c,a)\,e^{-(c\mu-\lambda)t} \qquad\Longrightarrow\qquad P(W_q \le t)\;=\;1-C(c,a)\,e^{-(c\mu-\lambda)t}$$

นี่คือสูตรที่ศูนย์บริการทั่วโลกใช้ตั้งเป้าแบบ "80/20" (รับสาย 80% ภายใน 20 วินาที) และเป็นฐานของฟังก์ชัน wq_percentile() ใน FlowLens ที่ใช้ตอบว่า "เปิดกี่โต๊ะ ผู้ป่วย 90% จึงรอไม่เกิน 15 นาที"

5. การรวมคิว — ของฟรีที่มีอยู่จริง

นี่คือผลลัพธ์ที่ทรงพลังที่สุดของ M/M/c และเป็นข้อเสนอที่ไม่ต้องใช้เงิน เอาคิวที่แยกกันมารวมเป็นแถวเดียวที่ป้อนทุกโต๊ะ

จำตัวเลขจาก บทที่ 3 ได้ไหม — 8 ห้องแยกคิว แต่ละห้อง ρ = 0.909 รอ 25.2 นาที ถ้าเอามารวมเป็นแถวเดียว ρ ยังเท่าเดิมทุกประการ แต่…

ตัวอย่างที่ 4.2 — รวม 8 แถวเป็นแถวเดียว
แบบ ก: 8 ห้อง แยกคิวกัน (8 × M/M/1) λ ต่อห้อง = 0.2165 E[S] = 4.2 ρ = 0.909 Wq = ρE[S]/(1−ρ) = 0.909 × 4.2 / 0.0909 = 42.0 นาที แบบ ข: 8 โต๊ะ คิวเดียว (M/M/8) λ รวม = 1.732 a = 7.274 ρ = 0.909 C(8, 7.274) = 0.726 Wq = C/(cμ−λ) = 0.726 / (1.905 − 1.732) = 4.20 นาที ลดลง 90% โดยไม่เพิ่มคนแม้แต่คนเดียว // ถ้าใช้ cs² ของจริง (0.20) แทน exponential จะได้ Wq(G/G/1) = 25.2 นาที → Wq(G/G/8) = 2.5 นาที

เหตุผลเชิงกายภาพ: ในแบบ ก อาจมีห้องหนึ่งว่างอยู่ ขณะที่อีกห้องมีคนต่อแถวสามคน — เวลาว่างนั้นใช้ไม่ได้ ส่วนแบบ ข โต๊ะที่ว่างจะดึงคนถัดไปจากแถวกลางทันที ไม่มีเวลาว่างที่สูญเปล่าแม้แต่วินาทีเดียวตราบใดที่ยังมีคนรอ

ใช้ในงานจริงอย่างไร

  • แถวเดียวป้อนหลายช่อง แทนการให้ต่อแถวหน้าโต๊ะใครโต๊ะมัน (เหมือนธนาคาร/สนามบิน)
  • รวมเครื่องวิเคราะห์เป็นพูลเดียว แทนการล็อกเครื่องไว้กับแผนกใดแผนกหนึ่ง
  • ระวัง: การรวมคิวใช้ไม่ได้เมื่อแต่ละโต๊ะทำงานคนละชนิดจริง ๆ (เช่น เครื่องเคมีกับเครื่องโลหิตวิทยา) หรือเมื่อการเดินไปโต๊ะที่ว่างช้ากว่าที่ประหยัดได้
  • ข้อแลกเปลี่ยน: คิวรวมทำให้คนที่มาถึงเห็นแถวยาวน่ากลัวกว่า แม้จะรอสั้นกว่า — ต้องสื่อสารด้วยป้ายบอกเวลารอโดยประมาณ

6. M/M/c เชื่อถือได้แค่ไหน

สมมติฐานของ M/M/cความจริงในกรณีศึกษาผลต่อคำตอบ
เวลาบริการเป็น exponential (cs² = 1) lognormal, cs² = 0.06–0.40 (วัดได้ทั้ง 7 หน่วย) สูงเกินจริงมาก
คนมาแบบ Poisson (ca² = 1) มาเป็นกลุ่มตอนเช้า ca² อาจ > 1 ต่ำกว่าจริงได้
λ คงที่ตลอดเวลา λ เปลี่ยน 20 เท่าระหว่างวัน ต้องแบ่งช่วง
c คงที่เปลี่ยนตามกะ 4→9 โต๊ะ ต้องแบ่งช่วง
คิวไม่จำกัด ไม่มีใครเดินออก จริงพอสมควรสำหรับผู้ป่วยนอก ใช้ได้
cs² ที่วัดได้จริง — ไม่มีหน่วยไหนใกล้ 1 เลยสักหน่วย

แถวแรกของตารางข้างบนเป็นสมมติฐานที่ขาดมากที่สุดในกรณีศึกษานี้ เพราะ cs² คำนวณจากข้อมูลได้ทุกหน่วย และไม่มีหน่วยไหนเข้าใกล้ 1

หน่วยcs² ที่วัดได้ M/M/c สมมติทำไมจึงต่ำ
เครื่องเคมีคลินิก0.0611.00 เครื่องอัตโนมัติ รอบการทำงานเกือบคงที่
เครื่องโลหิตวิทยา0.0891.00 เครื่องอัตโนมัติเช่นกัน
ส่งผลเข้า HIS0.0911.00 งานกดปุ่ม ใช้เวลาใกล้เคียงกันทุกครั้ง
ลงทะเบียน0.1221.00 ขั้นตอนเป็นมาตรฐาน
รับและปั่นแยก0.1771.00 รอบปั่นแยกคงที่
จุดเจาะเลือด0.2011.00 คนทำ จึงผันแปรกว่าเครื่อง แต่ยังห่างจาก 1 มาก
ทวนสอบและยืนยันผล0.4021.00 สูงสุดในระบบ — เคสยากปนเคสง่าย ต้องใช้วิจารณญาณ

ผลของการสมมติ cs² = 1 วัดได้ตรง ๆ ที่เครื่องโลหิตวิทยา ซึ่งเป็นช่วงที่ระบบนิ่งพอให้ทั้งสองสูตรใช้ได้

// เครื่องโลหิตวิทยา ช่วง 08:00–08:30 λ = 0.652 ราย/นาที E[S] = 8.00 c = 7 ρ = 0.745 ca² = 0.898 (วัดได้) cs² = 0.089 (วัดได้) M/M/c (Erlang-C, บังคับ cs² = 1) → Wq = 1.69 นาที G/G/c (Sakasegawa, ใช้ค่าจริง) → Wq = 0.91 นาที เวลารอที่วัดได้จากข้อมูล → Wq = 0.87 นาที

Erlang-C ให้ค่าเกือบสองเท่าของความจริง ขณะที่ G/G/c คลาดจากของจริงราว 5% ความต่างเกือบทั้งหมดมาจากพจน์ (ca² + cs²)/2 ซึ่งเท่ากับ 0.49 ไม่ใช่ 1.00 — ถ้าเอาตัวเลข Erlang-C ไปวางแผนกำลังคน จะเผื่อเครื่องและคนไว้มากเกินจำเป็น ที่มาของ cs² และ ca² ทุกค่าอยู่ที่ จากไฟล์ข้อมูล ถึงตัวเลขในสูตร

สรุปคือ M/M/c ใช้คิดเร็ว ๆ ในหัวได้ดี และเป็นฐานของการคำนวณเปอร์เซ็นไทล์ แต่สำหรับตัวเลขที่จะเอาไปเสนอผู้บริหาร FlowLens ใช้ G/G/c ผ่านสูตร Sakasegawa ที่รับ ca² และ cs² จริงเข้าไปด้วย — ซึ่งคือหัวข้อของบทถัดไป
